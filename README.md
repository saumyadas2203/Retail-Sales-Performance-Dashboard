# Retail Sales Performance Dashboard

## Overview

This project presents an interactive Power BI dashboard designed to analyze retail sales performance across different regions, customers, product categories, and payment methods.

The dashboard helps identify key business trends, monitor profitability, evaluate customer purchasing behavior, and support data-driven decision-making.

---

## Key Insights

- Total Sales Amount: 438K+
- Total Profit: 37K+
- Total Quantity Sold: 5.6K+
- Average Order Value: 121K+

---

## Dashboard Features

### Sales Analysis
- State-wise sales performance
- Regional comparison of revenue generation
- Geographic distribution of orders

### Profit Analysis
- Monthly profit trend analysis
- Profit by product sub-category
- Identification of high and low performing segments

### Customer Insights
- Top customers based on sales contribution
- Customer purchasing patterns

### Product Analysis
- Quantity sold by category
- Sub-category performance evaluation

### Payment Analysis
- Distribution of transactions by payment mode
- Customer payment preferences

## Business Value

The dashboard enables stakeholders to:

- Track sales performance efficiently
- Monitor profitability trends
- Identify top-performing products
